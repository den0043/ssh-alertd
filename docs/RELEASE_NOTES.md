# Первый security-выпуск форка

Это предварительная версия с исправлениями парсинга успешного входа,
происхождения journald, обработки ошибок Telegram, маскирования секретов и
завершения мониторинга при EOF. Конфигурация службы root-owned, доступ службы
только для чтения. Подробности — SECURITY_PATCHES.md в исходниках и архивах.

Файлы: статические linux/amd64 и linux/arm64 ELF, архивы с документацией и
service-файлами, BUILDINFO.json, SHA256SUMS, LICENSES.txt. Номер версии и коммит
есть в BUILDINFO.json и выводе `ssh-alertd -version`. Go на целевом VPS не нужен.
Старые .deb/Arch-пакеты оригинала не входят в этот выпуск.

**Это черновик prerelease, а не стабильный/Latest-релиз.** Публикация остаётся
ручным действием после проверки CI и вложенных файлов. SHA256 не является
цифровой подписью. При недоступности демона/Telegram события могут потеряться:
постоянной очереди, cursor/replay/retry нет. Сквозная проверка systemd → новый
настоящий SSH-вход → Telegram на отдельном VPS ещё необходима.

Секреты не прикладывать к issue/логам. Если токен ранее утёк, отозвать и заменить;
патч не устраняет прежние утечки. Лицензия оригинала Apache 2.0 сохранена.
